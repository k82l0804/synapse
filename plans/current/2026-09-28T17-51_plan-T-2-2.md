## Context

`src/cli/index.ts` currently stubs all commands with "not yet implemented." The
`synapse add` command is the entry point to the entire system — nothing else can
work until a product is registered. `repos.yaml` already exists in the synapse root
(from the fox workspace setup) but does not yet have a synapse-specific write path.
`synapse.db` schema is created by T-2-1 (signal parser plan). This plan depends on
T-2-1 being complete so `openDb()` is available.

## Deliverables

### D-1: Implement `synapse add <path>` command handler

**Files to change:**
- `src/cli/index.ts` — UPDATE — wire `add` command to handler
- `src/cli/commands/add.ts` — NEW FILE — `add(path: string): void`

**Implementation notes:**
- Resolve `path` to absolute path using `path.resolve()`
- Verify it's a git repo: check for `.git/` directory — if absent, print error and exit 1
- Extract product name from directory basename (e.g., `/home/user/my-project` → `my-project`)

**Spec contract ref:** AC-1, HLT-1

### D-2: Idempotency check — already registered?

**Files to change:**

**Implementation notes:**
